# 注意力机制-8 NSA

稀疏注意力必须同时回答两个问题：怎样低成本找到值得读取的历史，以及怎样让模型在训练阶段就适应没有被读取的信息。NSA（Native Sparse Attention，原生稀疏注意力）将全局压缩、动态块选择和局部窗口组织成三条独立注意力路径，再通过可学习门控组合输出。

本篇是 DeepSeek 路线的研究支线回顾。NSA 论文发表于 2025 年，时间早于前面讨论的 DSA、V4 和 V4.1；放在这里是因为读者已经具备表示、选择、压缩与共享的知识。不能据此把 NSA 认定为 V4.1 的后继，也不能把某个模型的 DSA 直接改称 NSA。

依据为[原始论文](https://arxiv.org/abs/2502.11089)，重点核对其[方法 §3](https://arxiv.org/html/2502.11089#S3)与实验设置，查阅于 **2026-10-14**。本文关注模型机制，硬件相关内容只用于解释为何选择连续块。

## 00 为什么“只保留高分 token”还不够

假设当前 query 需要同时引用远处的函数定义、近期修改和一份全局约束。只用局部窗口会丢掉远处证据；只读压缩摘要可能丢掉精确符号；先完整计算所有逐 token 分数再取 Top-K，又可能把大量计算花在最终不会读取的位置上。

NSA 给出的组合是：用压缩路径提供便宜的全局概览，用这条路径的匹配结果估计哪些历史块值得细读，再在选中块内计算原始粒度注意力。局部窗口单独负责短距离依赖，避免远程路径只学会依赖附近 token。

这里的“原生”强调训练时就使用这种稀疏结构，与训练好完整注意力模型后才临时丢弃缓存或屏蔽连接有所区别。它不是对任意全注意力权重的无损替换。

## 01 先建立三路计算的整体关系

令 $t$ 为当前 query 位置，$q_t\in\mathbb R^{d_k}$，value 维度为 $d_v$。每条路径先独立计算标准注意力：

$$
\operatorname{Attn}(q,K,V)
=\sum_j\frac{\exp(q^\top k_j/\sqrt{d_k})}
{\sum_a\exp(q^\top k_a/\sqrt{d_k})}v_j
$$

三条输出记为 $o_t^{\mathrm{cmp}},o_t^{\mathrm{slc}},o_t^{\mathrm{win}}\in\mathbb R^{d_v}$，分别对应压缩、选择、局部窗口。最终输出为：

$$
o_t=g_t^{\mathrm{cmp}}o_t^{\mathrm{cmp}}
+g_t^{\mathrm{slc}}o_t^{\mathrm{slc}}
+g_t^{\mathrm{win}}o_t^{\mathrm{win}}
$$

$g_t^a=\sigma(\operatorname{MLP}_a(h_t))\in[0,1]$ 是根据当前输入产生的门控；MLP 是多层感知机，$\sigma$ 是 sigmoid。门控之间不要求和为 1。

```text
历史 ──可学习块压缩──> 摘要 K/V ──压缩注意力────────────> o_cmp
                                      │ 权重映射成块分数
                                      └──Top-n 块──原粒度注意力──> o_slc
近期历史 ─────────────────────────────局部注意力────────> o_win
三个输出 ─────────────────────────────可学习门控融合────> o
```

各路径拥有独立的 K/V 表示，减少局部与远程模式相互干扰。图中“原粒度”指每个 token 保留独立向量，不意味着它必须和其他路径共享同一份投影结果。[出处：论文 §3.2、§3.3.3](https://arxiv.org/html/2502.11089#S3.SS2)。

## 02 压缩路径：全局概览也直接参与输出

设压缩块长为 $l$，滑动步长为 $\delta$，以位置从 0 开始的约定，第 $s$ 个块为：

$$
C_s=\{s\delta,\ldots,s\delta+l-1\}
$$

只有块末尾不晚于当前可见边界时才可使用。压缩映射将块内 key 聚成一个摘要 key，将块内 value 聚成一个摘要 value：

$$
\bar k_s=\varphi_K(k_{s\delta:s\delta+l}),\qquad
\bar v_s=\varphi_V(v_{s\delta:s\delta+l})
$$

切片采用右端不含的记法，$\varphi_K,\varphi_V$ 是包含组内位置信息的可学习映射。它们不等于 CSA 的逐通道 softmax 门控，也不能未经核对就写成普通平均池化。

当 $\delta<l$，相邻压缩块重叠，边界信息有机会进入多个摘要。若当前有 $T$ 个可用于压缩的 token，完整摘要数为：

$$
N_{\mathrm{cmp}}=\max\left(0,1+\left\lfloor\frac{T-l}{\delta}\right\rfloor\right)
$$

压缩路径对这些摘要计算注意力，得到 $o_t^{\mathrm{cmp}}$。因此，即使某区域没有被选中细读，它仍可能通过摘要路径影响输出。这是 NSA 与只有选中 token 才进入主注意力的方案之间的重要差别。

## 03 选择路径：从摘要权重定位块，再读取 token

### 3.1 不另外扫描所有原始 key 来生成选择

压缩注意力已经产生 query 对摘要的概率：

$$
p_{t,s}^{\mathrm{cmp}}
=\operatorname{softmax}_s(q_t^\top\bar k_s/\sqrt{d_k})
$$

NSA 复用它们推导选择块的重要性。选择块大小记为 $b$，选择块按连续 token 分组；它不必等于压缩块长 $l$，也不必等于步长 $\delta$。

最直观的对齐特例为 $b=l=\delta$：每个摘要恰好对应一个选择块，直接使用摘要概率作为块分数。若压缩块重叠或两种块大小不同，则必须根据空间对应关系聚合摘要概率。论文式 9 给出了其对齐假设下的具体索引映射；不能随意把它替换成对原始 token 分数求平均。

用矩阵描述这个关系，可写成 $r_{t,a}=\sum_s A_{a,s}p_{t,s}^{\mathrm{cmp}}$。$A$ 是由块布局确定的映射，记录哪些压缩概率以何种重数进入第 $a$ 个选择块的分数；它不是额外训练的索引网络。这个写法用于说明数据流，具体重叠布局应落实到论文的映射公式。

### 3.2 共享一个 KV 组的 query 共同决定选哪些块

GQA（Grouped-Query Attention，分组查询注意力）中，多个 query 头共用一组 K/V。若每个头分别选择完全不同的块，共享读取的优势就会被削弱。NSA 在同一个 KV 组内聚合 query 头的块分数：

$$
R_{t,a}^{(g)}=\sum_{i\in\mathcal H_g}r_{t,a}^{(i)},\qquad
\mathcal B_t^{(g)}=\operatorname{TopN}_a R_{t,a}^{(g)}
$$

$\mathcal H_g$ 为第 $g$ 个 KV 组对应的 query 头集合。选中的块集合对组内头共享，随后各头仍独立计算逐 token 的注意力概率。

连续块选择同时利用了相邻位置相关性和共享读取结构，但它会带入无关邻居。选择粒度更大，索引地址更少，额外读取的非关键 token 也可能更多。这是模型设计与执行约束之间的取舍，不是“块必然优于 token”的结论。

### 3.3 读取的是选中块内的独立 K/V

若选 $n$ 个块，每块 $b$ 个 token，则细读路径最多处理 $nb$ 个逐 token 条目：

$$
\mathcal J_t^{(g)}=\bigcup_{a\in\mathcal B_t^{(g)}}B_a,\qquad
o_t^{\mathrm{slc}}=\operatorname{Attn}(q_t,K_{\mathcal J_t}^{\mathrm{slc}},V_{\mathcal J_t}^{\mathrm{slc}})
$$

这条路径回到原始 token 粒度，能够在同一选中块内区别对待函数名、参数和其他内容。与 CSA 直接读取压缩条目不同，NSA 的摘要还承担引导原粒度读取的职责。[出处：§3.3.2](https://arxiv.org/html/2502.11089#S3.SS3.SSS2)。

## 04 一个对齐特例：组内头怎样共同选择

设历史有 12 个 token，$b=l=\delta=4$，形成三个块。一个 GQA 组中两个 query 头的压缩注意力概率分别为：

| 头 | 块 0：0—3 | 块 1：4—7 | 块 2：8—11 |
|---|---:|---:|---:|
| 头 A | 0.6 | 0.3 | 0.1 |
| 头 B | 0.1 | 0.7 | 0.2 |
| 组内和 | 0.7 | 1.0 | 0.3 |

若动态选择一个块，整个组选择块 1，读取 token 4—7。头 A 单独最偏好块 0，但共享选择采用组级需求；在块 1 内，两个头仍可以具有不同的逐 token 权重。

```python
heads = [[0.6, 0.3, 0.1], [0.1, 0.7, 0.2]]
group_scores = [sum(h[a] for h in heads) for a in range(3)]
block = max(range(3), key=group_scores.__getitem__)
tokens = list(range(4 * block, 4 * (block + 1)))
assert block == 1 and tokens == [4, 5, 6, 7]
```

这是标准库的选择示例，省略因果尾块、固定激活块和门控。论文实际实验还固定保留初始块与局部块，所以不能把全部选择预算都解释为自由竞争得到的远程块。

## 05 为什么三路分别归一化，再用门控组合

局部模式通常易于学习，若所有候选只在一个 softmax 中竞争，模型可能主要利用局部信号，而没有充分训练全局摘要与远程选择。NSA 因此将三种信息来源隔离成独立注意力路径，再用门控控制贡献。

分别归一化意味着每路先形成自己的条件分布。即使同一个源 token 同时通过摘要、选择和局部路径影响输出，也属于不同表示和不同归一化过程，不能按重复 token 简单删除其中一项。

这与 V4 CSA/HCA 的局部条目、全局条目共同进入一次主注意力归一化不同。两者都组合局部与全局信息，但融合公式不同，不能仅凭结构图中的两条或三条箭头认定计算等价。

训练方面，离散 Top-N 的地址选择不会因此自动可微。关键是压缩路径本身直接参与语言模型输出，压缩映射能够沿这条连续路径获得训练信号；选择路径又训练模型在选中区域内细读。应把“整套结构可原生训练”与“离散排序处处可微”区分开。

## 06 成本分析：少读历史，不等于少存全部历史

论文实验使用压缩块长 32、步长 16，选择块长 64、选择 16 块，窗口宽 512；选择预算包括一个固定初始块与两个固定局部块。实验主干是 27B 总参数、3B 激活参数的 GQA/MoE 模型，不是某个后来的旗舰 checkpoint。[依据：§4.1](https://arxiv.org/html/2502.11089#S4.SS1)。

给定 32,768 个可压缩历史 token，摘要数为 2,047，选择路径至多读取 1,024 条，窗口路径读取 512 条。按三路分别计算的候选总数为 3,583，约为该历史长度的 10.9%。来源重叠不等于这三路工作可以直接去重。

这只是候选计数，不是速度倍数。以头维度成本 $D$ 概括匹配与聚合，单 query 的主要量级约为：

$$
O\left(D\left(\frac{T}{\delta}+nb+w\right)\right)
$$

长序列 prefill 则含有 $O(DT^2/\delta)$ 的压缩注意力项，固定步长下仍然保留二次长度依赖。选择路径本身近似 $O(DTnb)$，两者应分别分析。

同时，未来 query 可能选择今天未读的任何旧块，因此细粒度历史仍需保留。NSA 的目标主要是减少每次参与计算和读取的条目，不提供“只保留 Top-N 块便足够”的缓存容量保证。

## 07 与已学机制比较，以及验证边界

| 机制 | 如何定位相关历史 | 最终主读取粒度 | 全局与局部的关系 |
|---|---|---|---|
| DSA | 独立轻量索引器给 token 打分 | 选中 token 的 KV 表示 | 依具体模型结构 |
| NSA | 压缩注意力概率映射为块分数 | 摘要、选中块内 token、局部 token | 三路独立注意力后门控 |
| V4 CSA | 独立压缩索引 key 上 Top-K | 压缩条目与局部 token | 同一次主注意力归一化 |
| V4 HCA | 无动态 Top-K | 全部重压缩条目与局部 token | 同一次主注意力归一化 |

验证 NSA 时，应先核对压缩块与选择块的对应、因果掩码和组内共享选择，再核对各路径独立归一化与门控。质量分析需要分别移除压缩、选择或窗口路径，观察长距离检索、精确复制和局部建模的变化。

从一张稀疏图看见相似结构，不能证明模型采用同一个算法；更不能把社区推测或未合并 PR 当作官方模型架构证据。本文依据 NSA 原始研究定义，不把它自动归属到 V3.2、V4 或 V4.1。

NSA 补齐了“摘要引导块级细读”的设计思路。下一篇转向 **GLM 的稀疏注意力与原生 IndexShare**，比较另一个模型家族如何利用跨层选择冗余。
